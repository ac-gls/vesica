# Vault index

Agents start here after `AGENTS.md`. The team's shared home is linked at `Team/`
(start with `Team/README.md`).

| Folder | Holds |
|---|---|
| `Inbox/` | Unsorted captures |
| `Projects/` | Active work, one folder per project |
| `Decisions/` | Personal decisions and drafts of team decisions |
| `Calendar/` | Daily and meeting notes |
| `Archive/` | Finished material |
| `Sessions/agent-runs/` | One ledger note per agent task |
